LBM・γ計算アプリ（オフライン対応版）

■ 中身
  index.html              アプリ本体（計算はすべて端末内で行い、入力値はどこにも送信・保存しません）
  sw.js                   オフライン用（初回表示時にファイル一式を端末に保存）
  manifest.webmanifest    ホーム画面アプリとしての設定
  icon-*.png / apple-touch-icon.png  アイコン

■ 使えるようにする手順
  1. このフォルダの中身（README.txt 以外の7ファイル）を、https で公開できる無料の場所に置く
     例：GitHub Pages
       - GitHub で公開リポジトリを作る
       - 「Add file」→「Upload files」で7ファイルをアップロード（zip のままではなく展開したファイルを）
       - Settings → Pages → Source を「Deploy from a branch」、Branch を main・/(root) にして Save
       - 1〜2分後に https://<ユーザー名>.github.io/<リポジトリ名>/ で開けるようになる
     ※ URL を知っている人は誰でも開けます（入力値は保存されないので個人情報は残りません）
  2. スマホでその URL を開く
       iPhone：Safari で開く → 共有ボタン → 「ホーム画面に追加」
       Android：Chrome で開く → メニュー（︙）→ 「ホーム画面に追加」または「アプリをインストール」
  3. 一度オンラインで開き、ページ下に「✓ オフラインでも使えます」と出れば準備完了
     以降は機内モードでもホーム画面のアイコンから使えます

■ 更新するとき
  ファイルを差し替えるだけで、次にオンラインで開いたときに裏で新しい版が保存され、その次の起動から反映されます。

■ パソコンで使うだけなら
  index.html をダブルクリックで開くだけでも、ネットなしで計算できます。
